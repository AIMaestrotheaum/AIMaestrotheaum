# Setup

Prepared for `AIMaestrotheaum/AIMaestrotheaum`.

1. Upload the complete directory to the public profile repository.
2. Repository Settings → Actions → General → Workflow permissions → Read and write.
3. Add repository secret `METRICS_TOKEN` using a GitHub classic token with `read:user`.
4. Open Actions and run Metrics, Snake, and Charts and cards once.
5. The Snake workflow creates the `output` branch; the README references its generated SVGs.

The supplied template documents this same workflow model: portrait generation from
`assets/jacket.png`, self-rated radar from `assets/skills.json`, generated cards,
Metrics, Snake, and scheduled workflow updates.
